CDS 3.4 변경사항
================

1. 기본 일기도 CHT 소스 fallback
- 기본: https://dmdw.kma.go.kr/map/data/CHT/
- 백업 1: https://data.kma.go.kr/CHT/
- 백업 2: https://afso.kma.go.kr/data/CHT/
- 기본 URL 로드 실패 시 같은 상대경로를 백업 서버에서 순차 시도
- 분석장, 예보장, 위험기상, 앙상블 등 상대 CHT URL 전체에 적용

2. 산출물 우선 선택 방식
- 1차/2차 산출물 드롭다운의 미지원 항목을 더 이상 disabled 처리하지 않음
- 현재 모델 미지원 항목은 회색으로 표시하지만 클릭 가능
- 미지원 산출물 선택 시 "해당 모델에서는 지원하지 않는 자료입니다." 안내 표시
- 선택 산출물을 지원하는 모델로 자동 전환
- 모델 박스는 현재 선택 산출물을 지원하는 모델만 활성화

3. 초단기(KLAPS/VDAPS) 메뉴 통합
- 기존 klfs_vdps 전용 드롭다운 제거
- 초단기 산출물을 기본예상도(한반도, hkor)에 통합
- 동일 ID 산출물은 기존 hkor 항목에 KLAPS/VDAPS 패턴을 병합
- 초단기 전용 산출물은 hkor 목록 하단에 별도 그룹으로 추가
- 초단기 모델 선택 시 hkor 외 1차 메뉴는 회색으로 표시하되 클릭 가능

4. 분석장
- 대메뉴 진입 기본값: 분석일기도 / 지상일기도
- 입력 시각 기준 최대 72시간 전까지 최신 사용 가능 자료 검색
- 날짜/시각, 모델, 1차/2차 산출물 변경 시 동일 검색 방식 적용
- 분석장 런타임 슬라이더 범위: 기준 앞뒤 4장 -> 앞뒤 10장

5. 버전
- Chart Display System 3.3 -> 3.4
- index.html의 로컬 CSS/JS 캐시 토큰을 v=3.4로 통일

검증
- 전체 JavaScript node --check 통과
- CHT 3개 URL 후보 생성 확인
- 초단기 hkor 통합 후 product ID 중복 없음
- 미지원 산출물 선택 시 모델 자동 전환 확인
- 분석장 슬라이더 21개 프레임(-10~+10) 확인

6. 분석장 우측 보조 패널 추가 (3.4.1 누적 패치)
- 적용 1차 메뉴: 분석일기도, 분석일기도(한반도), 분석일기도(태풍영역)
- 분석일기도: 기본 / 적외+기본(관측O) / 수증기+기본(관측O) / 적외+기본(관측X) / 수증기+기본(관측X) / 관측값만
- 분석일기도(한반도): 위 항목 + 레이더+기본(관측O/X)
- 분석일기도(태풍영역): 기본 / 적외+기본(관측O) / 수증기+기본(관측O)
- 첨부 CSV 477행 중 중복 21행을 제거해 456개 조합을 대조
- 실제 파일명이 있는 신규 조합 189개를 URL 패턴으로 등록
- 현재 모델/산출물에서 미산출인 보조 항목은 회색 비활성화
- 기본 항목은 기존 patternByModel을 그대로 사용해 기존 표출 동작 보존
- 태풍영역 지상일기도(2hPa)는 CSV 전 모델 미산출이고 기존 제품도 없어 추가하지 않음
- 화면 표기 버전은 CDS 3.4 유지, 브라우저 캐시 토큰만 v=3.4.1로 갱신

추가 검증
- 전체 JavaScript node --check 통과
- 대표 조합 URL 생성 검증 통과
- 적용 제품 29개, 신규 파일 매핑 189개 확인
- 모델/산출물별 보조 항목 활성·비활성 테스트 통과

[CDS 3.4.2 - 초단기 공통 산출물 재배치]
- 위험기상 > 안정도(대류)-한반도에 KLAPS/VDAPS K Index, Showalter Index, Lifted Index 패턴 통합
- 기본예상도(한반도) 925 고도/기온/비습/바람을 지상 습수 상단으로 이동
- 초단기 surfce를 일반 acptot 항목에 모델별 패턴으로 통합
- 925 수렴/풍속을 850 수렴도/등풍속 바로 위로 이동
- VDPS 200/300 고도/기온/풍속을 일반 gph200 항목에 통합
- VDPS 계절 전환: 11~4월 gph300, 5~10월 gph200
- 화면 버전은 CDS 3.4 유지, 정적 자산 캐시 토큰은 v=3.4.2
